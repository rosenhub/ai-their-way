# Contributing

## Proposing a new skill

Open an issue with the **New skill** template. It asks for four things:

1. The group it's for.
2. The one sentence that group keeps saying about chatbots. ("It buries the answer." "It asks three things at once.") That sentence is usually the whole skill.
3. A real before/after pair.
4. Whether you're in that group, work with it, or care for someone in it. All three count. Say which.

If it holds up, fork a sibling repo (any of the eight — they're identical in shape), follow its structure, and open a PR here adding the row to the table. The hub only links; the skill lives in its own repo so it can trend on its own.

## What makes a skill fit

- One failure, named in one sentence.
- 12 rules, each testable by reading the response.
- A before/after that a stranger understands in ten seconds.
- A "what this is not" section. Every skill here says what it does not do.
- A benchmark: 48 prompts, a rubric that is the skill's self-check, and a lint that runs without an API key.
- Not clinical. If it diagnoses, treats, or monitors, it's not a skill.

## Rule changes to an existing skill

Go to that skill's repo and use its Rule proposal template. Not here.

## Hosts and translations

Also per-repo. The hub's install table mirrors theirs; open a PR here only to keep it in sync.
