# AI Their Way

### 让任何 AI 代理为自闭症、智力与发育障碍（IDD）和失智症用户服务的技能合集。

**8 个技能。0 行代码。10 秒安装。为默认设置没有考虑到的人而建。对所有人更好。**

[English](README.md)

```bash
curl -fsSL https://raw.githubusercontent.com/rosenhub/ai-their-way/main/install-all.sh | sh
```

</div>

---

| 技能 | 一句话 | 为谁而建 |
|---|---|---|
| [no-subtext](https://github.com/rosenhub/no-subtext) | 让 AI 说它真正的意思。 | 自闭症用户 |
| [what-did-they-mean](https://github.com/rosenhub/what-did-they-mean) | 粘贴对方说的话，弄清对方的意思。 | 自闭症成人 |
| [never-say-remember](https://github.com/rosenhub/never-say-remember) | AI 永远不说"你还记得吗？" | 失智症患者 |
| [easy-read](https://github.com/rosenhub/easy-read) | AI 用 Easy Read 标准写作。 | IDD 成人 |
| [presume-competence](https://github.com/rosenhub/presume-competence) | 一个词就是一整句话。 | 不说话的自闭症人士、AAC 用户 |
| [low-demand](https://github.com/rosenhub/low-demand) | 当他们不堪重负时，AI 安静下来。 | 过载状态、PDA |
| [is-this-a-scam](https://github.com/rosenhub/is-this-a-scam) | 粘贴它，弄清楚。 | IDD 成人、老年人 |
| [one-thing](https://github.com/rosenhub/one-thing) | 不是计划，不是清单，只有一件事。 | 执行功能差异 |

每个技能都是一个 markdown 文件：12 条规则、前后对比、16 个宿主的安装表、48 题基准测试。都不是临床工具。
