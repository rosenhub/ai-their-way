# AlwaysHere

**AI, their way.** Eight skills that change how Claude talks, built for autistic adults, adults with intellectual and developmental disabilities (IDD), and people living with dementia.

Every AI assistant is tuned for the average user. These skills retune it for the people that default fails first.

## The skills

| Skill | What it does | Built for |
|---|---|---|
| no-subtext | Says exactly what it means. No idioms, hints, or buried answers. | Autistic users |
| what-did-they-mean | Paste a message from a person. Get what they likely meant and reply options. | Autistic adults |
| never-say-remember | Never tests memory or corrects. Answers a repeated question the same warm way. | People living with dementia |
| easy-read | Writes in Easy Read: one idea per sentence, everyday words. | Adults with IDD |
| presume-competence | Treats one word as a whole sentence. Never talks down. | Nonspeaking people and AAC users |
| low-demand | Gets quiet when the user is overwhelmed. | Autistic people in overload, PDA profiles |
| is-this-a-scam | Paste a text, email, or offer. Get a plain verdict and what to do. | Adults with IDD, older adults |
| one-thing | Gives one next step, not a plan. | Executive-function differences |

## How to use

Install the plugin and the skills are available in every chat. To call one directly, name it: for example, "use easy-read" or "is this a scam?" and paste the message.

Set it up with the person, not for them. If they are an adult, show them and ask if they want it. They can turn it off any time.

## What this is not

Not a clinical tool, not therapy, and not a substitute for a person. The skills change how the AI communicates. They do not diagnose or treat anything.
